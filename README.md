# Cyber Bible

📖 一款完全在浏览器本地运行的提示词存储管理工具，帮助用户高效地组织、检索和管理 AI 提示词。

## ✨ 功能特性

### 提示词管理
- **新建 / 编辑 / 删除 / 查看**提示词
- **复制内容**到剪贴板
- **标签系统**：为提示词添加标签，支持自动补全
- **批注功能**：为每条提示词添加批注，记录使用效果和改进思路

### 分组管理
- 创建 / 重命名 / 删除分组
- 分组下提示词列表展示
- 删除分组时提示词自动变为未分组

### 快速查找
- **全局搜索**：实时搜索提示词标题、内容、标签、批注
- **关键词高亮**显示匹配内容
- **相关度排序**：按匹配字段数量 > 更新时间排序

### 关系图谱
- **力导向图**可视化展示提示词、分组、标签之间的关系
- **节点交互**：拖拽节点、点击高亮关联、双击跳转详情
- **关系编辑**：添加 / 删除自定义关系
- **无限画布**：鼠标拖拽平移、滚轮缩放、网格背景

### 数据管理
- **可视化数据库**：表格视图查看所有数据，支持排序和筛选
- **导出 JSON**：一键备份所有数据
- **导入 JSON**：支持合并 / 覆盖两种导入模式
- **本地存储**：使用 IndexedDB，数据完全保存在浏览器本地

## 🚀 快速开始

### 方式一：直接打开

直接用浏览器打开 `index.html` 即可使用。

> 推荐使用最新版 Chrome / Edge / Firefox

### 方式二：本地服务器

```bash
# 进入项目目录
cd Cyber_Bible

# 启动本地服务器（任选一种）
python -m http.server 8080
# 或
npx serve .

# 打开浏览器访问
# http://localhost:8080
```

## 🛠️ 技术栈

- **纯 HTML / CSS / JavaScript**，零依赖，无需构建工具
- **IndexedDB** 浏览器本地数据库
- **SVG** 图谱渲染

## 💾 数据存储

所有数据保存在浏览器 IndexedDB 中，不上传任何服务器。

| 数据表 | 说明 |
|--------|------|
| `prompts` | 提示词 |
| `groups` | 分组 |
| `annotations` | 批注 |
| `links` | 自定义关系 |

> ⚠️ 清除浏览器缓存 / 数据会导致数据丢失，请定期使用「导出 JSON」功能备份。

## 📖 使用指南

### 创建提示词

1. 点击顶部工具栏「+ 新建提示词」
2. 填写标题、内容
3. 选择分组（可选）
4. 添加标签（可选，输入后按回车）
5. 点击「创建」

### 搜索

在顶部搜索框输入关键词，实时匹配提示词的标题、内容、标签和批注。

### 图谱操作

| 操作 | 说明 |
|------|------|
| 拖拽节点 | 调整节点位置 |
| 点击节点 | 高亮关联节点，右侧显示详情 |
| 双击节点 | 跳转到提示词详情 |
| 空白处拖拽 | 平移画布 |
| 滚轮 | 缩放画布 |
| 添加关系 | 点击工具栏「🔗 添加关系」，依次点击两个节点 |
| 删除关系 | 点击工具栏「✂️ 删除关系」，点击要删除的关系线 |

### 数据备份

1. 进入「数据库」页面
2. 点击「导出 JSON」
3. 保存备份文件

### 数据恢复

1. 进入「数据库」页面
2. 点击「导入 JSON」
3. 选择备份文件
4. 选择导入模式（合并 / 覆盖）
